# Hero Camera Project

A modern mobile application built with React Native and Expo. Designed to deliver a seamless user experience, this project utilizes Expo Router for efficient tab-based navigation and implements a robust, cross-platform architecture.

## 🚀 Technologies
* **Frontend:** React Native, Expo[cite: 5]
* **Language:** TypeScript[cite: 5]
* **Navigation:** Expo Router (`app/(tabs)` structure)[cite: 5]
* **Code Formatting:** ESLint[cite: 5]

## ✨ Features
* **Tab-Based Navigation:** Smooth and intuitive screen transitions using Expo Router[cite: 5].
* **Responsive UI Components:** Includes custom themed components, collapsible views, and parallax scrolling (`components/` directory)[cite: 5].
* **Cross-Platform:** Fully optimized for both Android and iOS devices[cite: 5].
* **Haptic Feedback:** Enhanced physical interactions across the application (`haptic-tab.tsx`)[cite: 5].
